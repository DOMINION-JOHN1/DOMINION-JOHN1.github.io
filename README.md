# Dominion John — Portfolio

A responsive, static portfolio website for Dominion John. The site is built with plain HTML, CSS, and JavaScript, so it can be published directly with GitHub Pages without a build step.

## Preview locally

Open `index.html` in a browser, or run a small local web server from this folder:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a GitHub repository for the portfolio. For a user site, name it `DOMINION-JOHN1.github.io`.
2. Add the files in this folder to the repository and push them to the `main` branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. GitHub Pages will show the published address in the same settings panel.

The CV and portrait are in `assets/`; keep those files in the repository so the download and image links continue to work.
